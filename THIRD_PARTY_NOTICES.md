# Third-Party Notices

Planner is distributed with third-party software. This file lists those
components, their licenses and where to find them.

The portable builds also contain the upstream license texts, copied without
modification:

- `licenses/runtime-manifest.json`: exact versions, declared licenses and
  checksums of the Python runtime, the Python packages and the frontend
  libraries included in that build;
- `licenses/python/`: license files of each Python package and of Python;
- `licenses/frontend/`: license texts of the JavaScript libraries bundled in
  the interface (`license.md`, generated by Vite) and of Tailwind CSS;
- `licenses/microsoft-webview2/` (Windows only): license and notices of the
  WebView2 SDK libraries;
- `licenses/manifest.json`, the Qt folders and `licenses/qtwebengine/`
  (Linux only): see [Linux Desktop Components](#linux-desktop-components);
- `licenses/system-manifest.json` and `licenses/system/` (Linux only): see
  [System Libraries](#system-libraries-linux-only).

Versions listed below are the configured ones when pinned; the manifest records
the versions actually included in each build.

### Rust Libraries in Compiled Extensions

The compiled extensions of cryptography (`cryptography/hazmat/bindings/_rust`),
pydantic-core (`pydantic_core/_pydantic_core`) and rpds-py (`rpds/rpds`)
statically link Rust libraries (crates) whose license texts are not shipped in
the wheels. The exact crates and versions are listed in the `Cargo.lock` file of
the source distribution of each package on PyPI
([cryptography](https://pypi.org/project/cryptography/),
[pydantic-core](https://pypi.org/project/pydantic-core/),
[rpds-py](https://pypi.org/project/rpds-py/)), for the version recorded in
`licenses/runtime-manifest.json`. At the configured versions these crates are
under permissive licenses: mostly MIT and/or Apache-2.0, plus BSD-3-Clause,
Unicode-3.0, Zlib and Unlicense. Crates that also offer GPL-2.0 or LGPL-2.1 as
an alternative are used under their permissive option.

The cryptography extension also statically links
[OpenSSL](https://github.com/openssl/openssl), licensed under Apache-2.0; the
license text is in the cryptography license files (`LICENSE.APACHE`).

### System Libraries (Linux only)

PyInstaller copies into `_internal/` some shared libraries of the build system
that the bundle needs (for example GLib, GTK, OpenSSL, libffi and libstdc++).
During the build they are mapped to their Debian/Ubuntu packages by comparing
their SHA-256 hashes with the files reported by `dpkg-query`.
`licenses/system-manifest.json` lists for each package the
version, the libraries it provides, the source package and a link to its exact
source (Launchpad for Ubuntu, snapshot.debian.org for Debian), and
`licenses/system/<package>/copyright` contains the package copyright file with
its license texts.
